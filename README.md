# MyApplication67

Android приложение на Kotlin и Jetpack Compose с регистрацией через Supabase, гостевым режимом, профилем и публикациями рецептов.

## Запуск

1. Откройте проект в Android Studio.
2. Установите Android SDK 37 и JDK, предложенный Android Studio.
3. Создайте локальный `local.properties` с путём к Android SDK (Android Studio обычно делает это автоматически).
4. Запустите конфигурацию `app` или соберите проект командой `./gradlew assembleDebug` (`.\gradlew.bat assembleDebug` в Windows).

Публичный ключ и URL Supabase указаны в `app/build.gradle.kts`. Секретный ключ сервера в Android приложение добавлять нельзя.

## Данные

SQL-файлы в `supabase/` описывают схему профиля, публикаций и правила доступа. Edge Function `login-by-username` находится в `supabase/functions/`. В текущем проекте Supabase схема и функция уже развёрнуты; локальные SQL-файлы хранятся как исходники изменений.

Обычные публикации и личные данные профиля доступны только владельцу. Архив по умолчанию закрыт и становится публичным по настройке владельца. Фото аватара и данные гостевого режима сохраняются локально на устройстве.

Карточки в ленте, реакции и комментарии публичны. Их таблицы и хранилище фото `feed-images` описаны в `supabase/feed_cards.sql`. Карточки гостевого режима остаются только на устройстве.
